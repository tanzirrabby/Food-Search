# Mayer Dowa Restaurant - Food Cards App 🍽️

A responsive web app that displays food items from different countries in interactive cards. Developed as part of an internship assignment.

---

## Features

- Responsive card layout for desktop & mobile.  
- Search bar to filter food by country.  
- Hover effects for modern UI.  
- Playful font & gradient background.

---

## Tech Stack

- HTML5, CSS3, Tailwind CSS  
- JavaScript (ES6)  
- Git & GitHub (Deployed via GitHub Pages)

---
